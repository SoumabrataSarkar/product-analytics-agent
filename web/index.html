Data architecture

Logical layers within one SQLite database, rather than three separate database servers.

Bronze · Source

Original user, session, content, transaction and marketing records; preserve quality issues.

Silver · Trusted detail

Validated and deduplicated events, consistent dimensions, documented joins and lineage.

Gold · KPI marts

Precomputed business metrics with supported aggregation grains and freshness checks.
Bronze → Silver → Gold → Agent
Query rule: Prefer Gold only when it correctly supports the requested metric and segmentation. Drill into Silver for detailed RCA and Bronze for raw-source audits. Never sum distinct-user counts across overlapping grains.

What informs the agent?

Metric Registry

Trusted formulas, SQL, denominators, filters, date windows and exclusions.

Data Catalog

Tables, column meaning, grains, join cardinality, lineage and known caveats.

Shared skill

Question decomposition, RCA principles, evidence quality, limits and report contract.

Investigation lifecycle

  1. Understand the question and retrieve shared metric definitions.
  2. Validate coverage, freshness, source quality and the baseline movement.
  3. Form up to 3 hypotheses informed by initial observations.
  4. Test with SQL via the safe query tool, recording results, SQL and source layer.
  5. Continue if needed for at most 3 automatic rounds, unless an earlier stop is justified.
  6. Invite human input if important drivers remain unexplained; the user can also intervene earlier.
  7. Report quantified drivers, evidence, caveats, recommendations and remaining unknowns.
Hypothesis outcomes: Supported · Rejected · Inconclusive · Not tested. No forced root cause; evidence of association is not proof of causation.

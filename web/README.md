# Product Analytics Agent reference website

Open `index.html` in a browser. It is one self-contained HTML file with embedded styles, illustrations and JavaScript. No server, build step, API key or database is needed to read it.

For email handoff, attach this file (optionally rename it `product-analytics-reference.html`) and tell the reviewer to download it and open it in a browser. Email previews may not run its interactive controls. The reference itself works offline; GitHub documents and the database download require internet access. Private repository links require an invited, signed-in GitHub account.

The sections are Start here, Explorer, Architecture & flow, Data & design, and Evaluation. Start here includes setup, the download link and the same first prompt as `QUICKSTART.md`. Copy works where the browser permits clipboard access; the prompt remains selectable when it does not. Navigation supports URL fragments and browser Back/Forward. Printing includes every section.

This is a reference website, not an interface for running the agent. Investigations run in the reviewer’s own Codex or Claude Code environment using the repository and a local SQLite file. See [QUICKSTART.md](../QUICKSTART.md).
